# decisions

The ADR log for the repo-root project: append-only, descriptive, ungated. A decision with a real
chosen-vs-rejected fork gets a numbered file here. Nothing here is organized as a node — an ADR is a
record, not a spec.

ADR numbers continue those of [repobuddy's ADR log](https://github.com/repobuddy/repobuddy/blob/main/.agents/spec/design/decisions/README.md),
where 0003 was written. 0001 and 0002 stay there.
