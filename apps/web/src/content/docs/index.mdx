project-tracker is a plugin for Claude Code, Codex, and GitHub Copilot CLI. Its skills file issues
and plan epics and initiatives on the tracker a project routes each kind of work to.

It ships four skills: [`project-tracker`](/project-tracker/skills/project-tracker/),
[`issue`](/project-tracker/skills/issue/), [`epic`](/project-tracker/skills/epic/), and
[`initiative`](/project-tracker/skills/initiative/). They moved here from
[repobuddy](https://github.com/repobuddy/repobuddy).
